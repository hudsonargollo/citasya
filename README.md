# CitasYa Monorepo

## Overview
CitasYa is an on-demand booking, appointment scheduling, and multi-vendor marketplace platform for beauty salons, barbershops, spas, and wellness professionals.

## Workspace Structure
- **backend/**: Laravel 10 REST API, Admin Control Panel, and Vendor Web Portal.
- **app-customer/**: Flutter mobile app for customers (booking, discovery, reviews, payments, notifications).
- **app-owner/**: Flutter mobile app for salon/barber owners and service providers (booking management, calendar, earnings).
- **docs/**: Vendor and module documentation.
- **_archives/**: Original raw upstream packages (ignored in git).

## Stacks
- Backend: Laravel 10 / PHP 8.1+ / MySQL / Blade AdminLTE
- Customer App: Flutter (Dart sdk >= 3.3.3) / GetX / Dio / Firebase
- Owner App: Flutter (Dart sdk >= 3.3.3) / GetX / Dio / Firebase
